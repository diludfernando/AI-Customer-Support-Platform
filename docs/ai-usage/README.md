# AI Usage Logs

This folder contains the mandatory AI usage documentation.


## Log format (per student)

For each significant AI-assisted session, record:

```markdown
## Session [Date]

**Tool used:** GitHub Copilot / ChatGPT / Antigravity / etc.
**Task:** What were you trying to accomplish?
**Prompt(s) used:** (summarize or paste key prompts)
**Output:** What did the AI generate?
**What I changed:** What did I modify, accept, or reject from the AI output?
**Reflection:** Did the AI help? Did it introduce errors you had to fix?
```

## Rules

- Be honest — this is an academic integrity requirement
- Log all significant AI assistance, including code generation, debugging help, and design suggestions
- Do not log trivial autocomplete suggestions
